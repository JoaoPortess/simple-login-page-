# Login page

A responsible login page built with HTML and CSS.

## About the project

This project consists of a simple login page built with HTML and CSS.
The main goal of this project was to practice and improve my HTML and CSS skills by building a responsive interface from scrath.

## Tecnologies

- HTML
- CSS

## Features

- Responsive design
- Glasmorphism effect
- Flexbox-based layout
- interactive button hover effect
- Input focus states

## What I Learned

During this project, i practiced and improved my understanding of:

- Semantic HTML structure
- CSS Flexbox
- CSS pseudo-classes and pseudo-elements
- Glasmorphism
- Responsible design with media queries
- The CSS box model 

## How to run

1. Clone this repository
2. Open the project folder
3. Open 'index.html' in you browser
